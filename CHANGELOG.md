# Builder Wands v1.0.0

The first release of Builder Wands introduces fast connected-surface building for Minecraft Bedrock Edition.

## Features

- Added Wood, Stone, Copper, Gold, Iron, Emerald, Diamond, and Netherite Builder Wands.
- Each tier provides increased placement capacity and durability, up to 64 blocks per use.
- Added surface-based placement on floors, ceilings, and walls.
- Copied blocks preserve the source block's state and orientation.
- Added Full Block and Smart Outline placement previews.
- Added per-player commands for preview visibility and mode selection.
- Added inventory costs, Wand durability, material-based repairs, and Creative mode support.
- Added collision checks, protected block rules, and placement rollback safeguards.
- Added survival recipes, including a Netherite Smithing Table upgrade.
- Added custom textures, sounds, and English and Spanish localization.

## Compatibility

- Standalone and compatible with other addons through its independent namespace and block tag.
- Requires Minecraft Bedrock 1.21.90 or newer.
